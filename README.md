# Sistema Integral de Gestión de Clientes, Servicios y Reservas (Software FJ)

## Descripción del Proyecto
Este proyecto es un sistema integral orientado a objetos desarrollado en Python, diseñado para gestionar clientes, servicios y reservas para la empresa "Software FJ". El sistema no utiliza bases de datos; toda la gestión se realiza en memoria mediante listas y objetos.

El objetivo principal de esta aplicación es demostrar la correcta aplicación de los principios de la Programación Orientada a Objetos (POO) como abstracción, herencia, polimorfismo y encapsulamiento. Además, el sistema cuenta con un manejo robusto y avanzado de excepciones para garantizar su estabilidad ante cualquier error, registrando todos los eventos en un archivo de logs.

**Nota Técnica sobre la Interfaz:** La interfaz de usuario está desarrollada en **Modo Consola (Terminal)**, siguiendo las indicaciones del tutor para garantizar la compatibilidad de ejecución en entornos en la nube y repositorios como GitHub, evitando los errores de display asociados a librerías gráficas de escritorio como Tkinter.
